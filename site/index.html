Read-aloud

Maze is a self-hosted web application where you prepare your tabletop RPG campaigns, alone or with co-GMs: characters, factions, places, maps and scenarios, written together in real time.

NPCs and factions live on a relationship graph, places in a tree with interactive maps, and scenarios in a collaborative editor that links to all of them.

Self-hosted, free and open source (MIT). One Docker container, one SQLite database. Interface in English and French.

Scenarios you write together

A campaign page, scenarios and nested sub-pages for acts, scenes and handouts, each with a status: draft, ready, in progress or played.

  • Read-aloud and GM secret boxes, tables, images, templates, a reading mode and clean printing.
  • @ mentions of NPCs, factions and places, which link the page to their sheets.
  • Real-time collaboration: several GMs edit the same page and see each other's cursors. Offline edits are merged on reconnection; what cannot be merged is kept in the page history.
  • Comment threads anchored to passages, and a version history with named versions and one-click restore.

NPCs, factions and places

Every character, faction and place has its own sheet, with what you need at the table and what the players must not see.

  • NPC sheets: portrait, status, hook, personality, motivations, GM secrets, gallery.
  • Faction sheets: colour, emblem, goals, resources, members and their role.
  • Places in a free hierarchy (region, city, building, room), with the NPCs and factions present.
  • Search across the whole campaign with Ctrl+K.

A relationship graph

NPCs and factions on one board: who owes whom, who spies for whom, who wants whose job.

  • Typed relations (ally, enemy, family, rival, mentor, debt and your own), one-way or mutual, optionally secret.
  • Views for a scenario's cast, for the factions, or for a place.
  • Free placement, zoom, PNG export, and an automatic layout that keeps the most readable of several arrangements.

Interactive maps

Upload a map of up to 8192 pixels and pin your places on it.

  • Rings of sub-places open around a pin, and a place with its own map can be entered.
  • The place's sheet opens beside the map, with who is there.
  • Custom icons per place type.

Your server, your data

Maze runs as a single Docker container with a SQLite database. Everything stays on your machine.

  • Backups and restore from the web interface, plus a daily timer.
  • One-click updates from the administration, with automatic rollback if the new version is not healthy.
  • Two roles: administrator, and GM who sees only the campaigns assigned to them.
  • Campaign export and import as a .zip file.

Claude connector (MCP)

Maze includes a remote MCP server with its own OAuth 2.1 authorisation. Claude can search and read your campaigns and, if you allow it, edit sheets, relations and scenario pages, comment, add images and pin places on maps.

Each authorisation needs an administrator's password, actions are logged, and pages keep their version from before Claude's change.

Foundry VTT import

Your instance serves a module for Foundry 13 and 14. It imports a campaign, or what one scenario needs: a journal per NPC, faction and place, with secrets on a GM-only page, and a scene per interactive map with a note per pin.

The import is one-way and repeatable. Actors are filled in for the Dark Heresy systems only.

English and French

Every screen, every server message, the data created with a campaign and the Foundry module are available in both languages. Each GM chooses theirs in the account menu.

The detailed guide is in French. Other languages are welcome: the translation guide explains how.

What to know before you install

  • Maze is used in production by its author and has been through a thorough audit, but it is young as a community project, with one maintainer: reviews and answers may take a while.
  • It is developed with substantial help from Claude (Anthropic), under the direction and review of its author.
  • You need your own server: Docker, a domain name and a reverse proxy for HTTPS. There is no hosted version and no online demo; the repository includes a demo campaign you can load into your instance.
  • The core is system-agnostic. The detailed guide and the architecture notes are in French.

Get started

Requirements: a Linux server with Docker and the Compose plugin, at least 10 GB of disk (the update script rebuilds the image next to the running one), a domain name, and a reverse proxy that terminates HTTPS. The examples use /opt/maze, maze.example.org and Caddy.

  1. Get the code

    sudo mkdir -p /opt/maze && sudo chown "$USER": /opt/maze
git clone https://github.com/ranglier/Maze.git /opt/maze
cd /opt/maze
cp .env.example .env
install -d -m 2775 control

    control/ receives the container's requests to the update service. The container runs as UID/GID 1000: if id -u is not 1000, also run sudo chgrp 1000 control.

  2. Administrator password (Docker secret)

    Masked input, run on its own (the length is shown to confirm):

    read -rs -p "Maze admin password: " MAZE_PW && echo " - entered (${#MAZE_PW} characters)"

    Then:

    mkdir -p secrets
printf '%s' "$MAZE_PW" > secrets/maze_password.txt
unset MAZE_PW
chmod 600 secrets/maze_password.txt
sudo chown 1000:1000 secrets/maze_password.txt

    It is used once, to create the admin account; secrets/ is ignored by git.

  3. Edit .env

    MAZE_BIND=127.0.0.1
MAZE_PUBLIC_URL=https://maze.example.org
FORWARDED_ALLOW_IPS=

    MAZE_BIND is 127.0.0.1 if the reverse proxy runs on the same machine, otherwise this machine's private IP; never 0.0.0.0 (Docker's published ports bypass firewalls such as ufw). For FORWARDED_ALLOW_IPS, see Configuration.

  4. Start

    docker compose up -d --build
docker compose logs -f maze

    Optionally, load a demo campaign: docker compose exec maze python -m maze.demo (add --lang en for an English one; default: MAZE_DEFAULT_LOCALE).

Then point your reverse proxy to Maze and sign in as admin: the README has the Caddy configuration and first login, the daily backup timer and the update service. A step-by-step installation on a fresh Debian server, in French: deploy/installation-debian.md.
